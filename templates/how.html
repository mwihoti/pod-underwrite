Method

Four steps, in this order, every time. If any step cannot finish, the verdict is INCONCLUSIVE and the page says which step failed.

1. Decode the netlist

The bytes are decoded as TAP-02 section 2 records: NAND (7 bytes), LATCH (4 bytes), REF (31 bytes + 3 per input). The decoder must re-encode the stream byte-for-byte and the record stream must be structurally well formed (no reads of future signals, enough signals for the declared outputs). Anything else is INVALID, and the first failing rule is printed.

The decoder was validated against a live TapeOut deployment on BNB Chain: 24 circuits decoded, re-encoded and matched eval/step on chain, including the LATCH-forward case where a latch's d points at a later record.

2. Check the tape-out bounds

PoD refuses designs outside its limits and refuses REF entirely. A netlist that could never have been taped out is reported as GATE-LIMIT with no verdict, rather than being judged on gates that are irrelevant to the market.

3. Compare against the protocol's own correctness surface

Each task publishes 256 vectors, each with a Merkle proof. This service rebuilds every leaf as keccak(keccak(abi.encode(index, input, expectedOut))), folds each proof with a commutative pair hash, and checks that all 256 fold to the published task root. Only then are the vectors used. 

leaf = keccak( keccak( abi.encode(uint256 index, bytes input, bytes expectedOut) ) )
node = keccak( min(a,b) || max(a,b) )
root = task.root   ← checked, not assumed

The candidate is then evaluated on those same inputs and the output bit-vectors are compared. The comparison reports the lowest differing input, which is the value a challenger would use.

For combinational tasks the whole vector set is used. For sequential tasks each vector is applied as a cycles-frame run from the zero latch state; because the published frame schedule is not specified, a divergence there is reported as INCONCLUSIVE, never as a mismatch. If you supply a reference netlist, the engine enumerates every input instead and only then claims exhaustive coverage.

4. Cost it, then say what it does not prove

A = nand + 7·latch, C = A · max(depth,1)³, and bonus = clamp(k·cRef/C, ⌈k/4⌉, 4k). Cost is computed from the decoded netlist. Where the protocol's verifier answered the same question, both numbers are shown side by side.
